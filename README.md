 🏡 Exploratory Data Analysis (EDA) of House Prices

 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the **Ames Housing Dataset** to understand the factors that influence house sale prices.

The main objective is to explore the dataset, identify patterns, analyze relationships between variables, detect outliers, and visualize important insights using Python.

This project focuses only on data analysis and visualization, without applying Machine Learning models.

 🎯 Objectives
- Understand the distribution of house sale prices.
- Identify numerical features correlated with SalePrice.
- Analyze the relationship between overall quality and house prices.
- Compare house prices across different neighborhoods.
- Detect and analyze outliers.
- Identify and handle missing values.
- Create meaningful visualizations and a final dashboard.

 📊 Dataset
**Dataset:** Ames Housing Dataset

**Source:** [Kaggle – House Prices: Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data)

- Approximately 1,460 rows
- 81 columns
- Target variable: `SalePrice`
